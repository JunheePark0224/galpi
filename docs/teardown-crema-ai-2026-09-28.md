# YES24 크레마AI 직접 사용 기록 — 2026-09-28

본인 계정(로그인)으로 YES24 홈의 "AI와 대화하며 도서를 추천받아 보시겠어요?" → chat.yes24.com (크레마AI).
캡처: `assets/crema-ai/01_data-analysis-query.png`

## 질문
> 데이터 분석을 깊이 있게 배우고 싶은데, 통계는 쉽게 설명해주는 책을 추천해줘. 지금 데이터 분석 과정을 듣고 있는 입문자야.

## 결과
- YES24 안에서 검색어 8개로 직접 검색 → 후보 중 3권의 **상세·목차를 열어 확인** → 답변 (약 40초 이상)
- 3권 추천, 각 권마다: 저자/출판사, **가격(정가·판매가)**, **평점**, 주요 내용(목차 기반), **추천 이유(내 상황과 연결)**
  1. 통계 101×데이터 분석 — "코드는 짜는데 통계량 의미를 모를 때 길잡이"
  2. 혼자 공부하는 데이터 분석 with 파이썬 — "지금 듣는 과정에서 코드 실습과 통계 기초를 정리할 자습서"
  3. 세상에서 가장 쉬운 통계학 입문 — "수학 부담 없이 통계 원리만"
- 답변 끝에 책 카드 3장: 표지·제목·저자·평점(리뷰 수)
- 입력창 위에 "RBTI 추천 — 테스트 하기" (독서 성향 테스트형 추천)

## 판단
**갈피가 하려던 핵심(목적을 말하면 → 목차 근거로 → 여러 권을 가격·평점과 함께 추천)을 이미 잘 하고 있다.** 추천 품질도 좋다(실제로 입문자에게 맞는 3권, 이유가 구체적).

관찰된 한계 (계정 1개·질문 1개 관찰):
- 결과가 **긴 대화 글**이다. 3권을 비교하려면 위아래로 스크롤해야 하고, 가격·평점·난이도를 나란히 보는 화면이 없다. 하단 카드에는 표지·평점만 있다
- 원하는 걸 **문장으로 잘 써야** 한다
- 답이 나오기까지 **40초 이상** 걸린다 (검색·상세 확인 과정을 보여줌)
- 진입점이 홈의 작은 문구 링크, 별도 창(chat.yes24.com)으로 열린다. YES24를 가끔 쓰는 사용자(본인)도 존재를 몰랐다 — 1명의 경험이므로 일반화하지 않는다

# RBTI Lab (rbti.yes24.com) — 크레마AI 입력창 위 "RBTI 추천 · 테스트 하기"

"Reader Behavior Type Indicator — 내 책장 속에는 어떤 강아지가 살고 있을까?" **참여 385,509명** (9/28 화면 기준).

## 구조
- 질문 12개, 선택지 2개씩. 확인된 질문: 1 "보통 한 번에 몇 권의 책을 읽나요?" · 8 "당신의 장바구니 현황은?" · 9 "서점에 갔을 때 나는 보통 어디로 향하는가?" · 10 "소설 속 주인공이 시련을 겪는다면?" · 11 "책을 읽으며 더 자주 하는 행동은?" · 12 "가장 최근에 읽은 책은?" (2~7번은 기록 누락)
- 4개 축 → 16유형, 유형마다 강아지 캐릭터: 완독형/선택형 · 분석형/공감형 · 깊이형/넓이형 · 정보형/재미형
- 결과 화면: 유형 코드 + 강아지 + 해시태그 + 성향 설명 → "OOO를 위한 추천상품" 8~9권(표지·제목·저자·평점만)

## 실험: 정반대로 두 번 응답 (실제 취향 아님, 구조 확인용)
| | 1회차 (모두 첫 번째 선택지) | 2회차 (모두 두 번째 선택지) |
|---|---|---|
| 유형 | **CADI 단서 찾는 비글** — "깊고 철저하게 파고드는 학구파" | **SEBF 낭만 몽상가 스피츠** — "기분 따라 감성의 책을 유쾌하게" |

## 판단
- **정반대 유형인데 추천 3권이 겹친다** (흔한남매 23, 세네카, 한국사 이상현상 연구원). "학구파" 결과에 어린이 학습만화(에그박사, 흔한남매)가 섞여 있다
- 추천 목록 상당수가 **현재 베스트셀러**(한국사 이상현상 연구원, 머니 트렌드 2027, 시대예보, 브레인 악셀 — 같은 날 알라딘 추천마법사 기본 목록에도 있음)
- **추천 이유가 없다.** 유형과 책을 잇는 설명이 없다
- 결과의 주인공이 **나(강아지 유형)** 다 — 밀리 성향 테스트와 같은 구조
- 한계: 같은 계정 2회. 추천이 유형이 아니라 계정 이력·인기도에 따라 정해질 가능성도 있음 — 다른 계정이나 로그아웃 상태 비교는 안 함

→ **참여는 크다(38.5만 명). 그런데 유형 결과에서 책으로 넘어가는 연결이 약하다.**
