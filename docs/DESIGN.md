## 1. 원칙

1. **책이 주인공, 책갈피가 얼굴** — 화면의 중심은 오래된 책 한 권과 그 위로 꽂힌 책갈피. 나머지는 물러선다
2. **심플하게, 조금 귀엽게** — 민음사 책갈피의 단정함(반투명 필름·명조 제목·가는 선) + 무작위 동물 그림 하나만큼의 귀여움. 장식을 더하지 않는다
3. **민음사와 닮지 않게** — 직사각형 카드·왼쪽 세로 띠·두 줄 색 띠·저자 사진·출판사 로고 자리는 쓰지 않는다. 분위기만 참고하고 모양은 갈피 것(아치 창 + 제비꼬리)
4. **모으고 싶게** — 책갈피 한 장 한 장이 달라서, 내 서재에 꽂히는 순간이 보상
5. **따뜻한 종이, 다크 모드 없음** — 크림색 종이가 정체성이라 MVP는 밝은 화면 하나로 간다

### T-04b 화면 폭 — 모바일 우선, 데스크톱은 가운데 기둥 (09-29)

- 기준은 휴대폰(360~430px). 링크를 카톡으로 받는 이용자가 대부분
- **데스크톱 전용 레이아웃은 만들지 않는다.** 넓은 화면에서는 모바일 화면(최대 430px)을 **가운데 기둥**으로 두고, 양옆은 나무 책상 느낌의 옅은 바탕(`paper-deep`)으로 채운다 — 채용담당자가 노트북으로 열어도 깨져 보이지 않게
- 기기 비율은 1단계에서 기록(`visit` 공통 속성의 기기 종류)으로 확인하고, 데스크톱이 많으면 2단계 후보로

### T-05 간격·모서리

- 간격: 4 · 8 · 12 · 16 · 24 · 32 px
- 모서리: 버튼·칩 `999px`(알약), 카드 `12px`, 책 `2px 10px 10px 2px`(책등 쪽이 각짐), 책갈피 위 `10px 10px 0 0`
- 누를 수 있는 것은 **최소 44 × 44 px**

## 4. 책갈피 규격 (C-02) — 사용자가 그림을 그릴 때 기준

```
        │  끈 (장르 색, 1.5px, 위로 약 26px)
        ●  매듭
   ╭────○────╮  ← 구멍 (지름 8)
   │ ╭─────╮ │  ← 아치 창: 너비 = 카드 − 18, 높이 약 35%, 위 모서리 반지름 = 창 너비의 절반
   │ │ 그림 │ │     동물은 창 가운데 아래쪽(60% 높이)에 얼굴
   │ ╰─────╯ │
   │ [에세이]  │  ← 장르 이름표
   │ 제목     │  ← 고운바탕 15/700, 두 줄까지
   │ 한 줄    │  ← 고운돋움 13, 네 줄까지
   │ - - - - │  ← 바느질 선 (장르 색, 점선)
   │   갈피   │
   ╰───╲╱───╯  ← 제비꼬리: 가운데가 높이의 7%만큼 파임
```

| 항목 | 값 |
|---|---|
| 비율 | **약 1 : 2** (기준 112 × 224, 화면에서는 가로 160 × 세로 344px로 키움 — 09-30 큰 글씨 대응으로 +24px) |
| 책 위로 튀어나온 부분 | 높이의 약 25% (끈 + 아치 창 윗부분) |
| 그림 영역 | 아치 창 안. 그림 파일은 **정사각형 100 × 100 viewBox SVG**, 창에 맞게 잘라 보여준다 |
| 글자 영역 | 창 아래. 그림이 글자 영역을 침범하지 않는다 |
| 한 책 한 책갈피 | 서재에는 책 한 권에 책갈피 하나. 같은 책을 다시 보관하면 "이 책갈피로 바꿀까요?" |

**그림 조합** = 동물 × 배경 × 하늘 소품 × 땅 소품 (+ 희귀). 뽑을 때마다 무작위, 보관할 때 조합 번호를 저장해 서재에서 그대로 다시 그린다 (PRD D-05). 동물 7 × 배경 6 × 하늘 5 × 땅 5 = **1,050가지**.

**배치 규칙** (09-29 시안 확인): 동물 파일은 100 × 100 그대로 두고, 창 안에서 **55% 크기로 줄여 언덕 위에 앉힌다** — 배경과 소품이 보이도록. 하늘 소품은 창 위쪽, 땅 소품은 언덕 양옆. 초안 7종: `../assets/animals/*.svg` (Claude 초안, 사용자 수정·교체 가능)
