# 도전 규칙 v2 — "큰 목적은 유지, 그 안에서 한 발짝" (2026-10-05, 사용자 확정)

## 원칙

도전은 "다른 책을 무작위로 보여 주기"가 아니다. **사용자가 고른 큰 목적(이야기 / 배우기)은 유지하고, 그 안에서 평소라면 고르지 않았을 영역으로 한 발짝 옮긴다.**
- 일반 분류(이야기 / 배우기)는 바꾸지 않는다. **배우기 + 도전**일 때만 교양 영역(과학 교양·인문·역사·예술·여행·사회·시사)을 "배움의 확장 영역"으로 허용한다. 과학 교양은 배우기 도전에서 자연스러운 배움의 영역이다.
- 배우기 도전은 시·에세이·한국 소설·외국 소설·SF·판타지·추리·스릴러·호러·괴담으로 **가지 않는다**. 이야기 도전은 이야기 안에서만 (지금과 같음).
- **사용자의 과거(꽂은 책·이전 선택)를 보지 않는다** — 과거 취향에 묶이지 않게 (사용자 결정). 주제·장르를 고르지 않았으면 갈피가 정한 **도전 목록**에서 고른다.
- 도전 목록은 **책이 5권 이상인 영역만** 후보, 후보 중 **같은 확률**, 뽑기 seed로 정해 다시 계산해도 같다. 책이 늘면 코드 변경 없이 후보가 늘어난다.
