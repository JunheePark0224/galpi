# 새 칸 5개 + 1,000권 배분 (2026-10-05, 사용자 확정 — 정의도 10-05 확정, 키워드는 초안)

## 결정

- **이야기 +1: 로맨스.** 고전은 장르가 아니라 '시대' 속성 — 공개 뒤 검토 (원작 연도 태그 필요).
- **배우기 +4 (둘씩 나눔):** 마케팅·브랜딩, 리더십 (일을 더 잘하기) · 건강·운동, 요리·살림 (나를 더 잘 돌보기).
- 내용 장르가 출처 장르보다 먼저 (지금 규칙과 같음): 한국·외국 소설 중 사랑이 중심이면 로맨스 칸.

| 리더십 | 배우기 (일) | 사람과 팀을 이끄는 법 — 팀장·관리자, 피드백·위임, 조직 문화 | 위인전·정치인 자서전 | 팀 이끌기 · 피드백·코칭 · 조직 문화 |

## 질문 지도 자리 (선택지 문구 초안)

- `story-fiction` A "현실에 발 딛은 소설" genres에 로맨스 추가 → 새 노드 `story-real`: A "설레는 사랑 이야기"(로맨스) / B "삶을 그린 소설"(한국 소설·외국 소설 → `story-novel`).
- `learn-area` A·B topics에 새 주제 추가.
- `learn-work` B를 "일하는 방식과 사람"(커리어·글쓰기·시간·마케팅·브랜딩·리더십) → 새 노드 `learn-craft-people`: A "나를 다듬기"(지금 `learn-craft`) / B "함께 움직이기"(마케팅·브랜딩·리더십) → 새 노드 `learn-reach`: A "알리고 팔기"(마케팅·브랜딩) / B "사람을 이끌기"(리더십).
- `learn-life` B "하루와 살림"(습관·돈·경제·건강·운동·요리·살림) → 새 노드 `learn-daily-body`: A "몸과 생활"(건강·운동·요리·살림) → 새 노드 `learn-body`: A "몸 움직이기"(건강·운동) / B "밥과 살림"(요리·살림) · B "습관과 돈"(지금 `learn-daily`).
- 새 주제마다 키워드 고르는 질문 끝(지금 다른 주제처럼) — 키워드가 5권 미만이면 그 선택지는 넓히기 규칙대로.

## 도전 규칙 (원칙: 큰 목적 유지, `docs/plans/2026-10-05-challenge-rules.md`)

| 원래 | → | why (초안 메모, 화면에 안 보임) |
|---|---|---|
| 로맨스 | SF·판타지, 역사 | 두 사람의 이야기 → 더 큰 세계와 시간 |
| 마케팅·브랜딩 | 예술·여행, 인문 | 파는 말 → 쓸모를 묻지 않는 아름다움 |
| 리더십 | 역사, 인문 | 이끄는 법 → 사람이 걸어온 시간 |
| 건강·운동 | 과학 교양 | 몸 쓰는 법 → 몸이 움직이는 원리 |
| 요리·살림 | 역사, 예술·여행 | 밥상 → 음식이 지나온 시간과 장소 |
| 함께 움직이기 (마케팅·브랜딩, 리더십) | 인문, 역사 | |
| 몸과 생활 (건강·운동, 요리·살림) | 과학 교양, 예술·여행 | |

로맨스는 소설 묶음 규칙(소설 전체 → 세상을 알아 가는 글 등)의 `from`에 함께 들어간다. 새 주제는 큰 묶음 규칙(일하는 방식 전체, 하루와 살림 전체, 나를 돌보기 전체, 일을 잘하기 전체)의 `from`에 함께 들어간다. 규칙 번호는 이어서 매긴다.
