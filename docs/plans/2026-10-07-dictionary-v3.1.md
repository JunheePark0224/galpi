# 정의서 v3.1 — 서재 검수 중에 나온 규칙 (모았다가 검수가 끝난 뒤 한 번에 넣는다)

서재 v3 다시 태그(library-v3.html) 검수 중에는 정의서를 고치지 않는다 — 기준이 움직이면 자동으로 정해진 책이 다시 옛 기준이 된다(10-06 결정).
검수가 끝나면 아래 규칙을 정의서에 넣고(v3.1), 그 규칙에 걸리는 책만 다시 태그한다.

| # | 날짜 | 규칙 (사용자 확정) | 예 | 다시 볼 책 |
|---|---|---|---|---|
| 1 | 10-07 | 선집이라도 모든 수록작이 하나의 내용 장르(SF·추리·호러·로맨스 등)로 묶여 소개되면 그 내용 장르를 먼저 고른다. 편 수 규칙은 형식만 섞이고 내용 장르가 없을 때만 쓴다. (장르 판단 순서에서 "시집이면 시"·"선집은 편 수"보다 앞에 둔다) | 선 끝에 → SF·판타지 (SF 소설 1편 + SF 시 7편) / 초판본 이상 선집 → 시 | 장르가 시·한국 소설·외국 소설인 선집 중 소개가 한 내용 장르로 묶인 책 |
| 2 | 10-07 | (얻는 것) 소설·시는 형식 자체가 약한 '마음' 신호다. 소개가 지식·원리를 알려 주는 것을 책의 **주된 목적**으로 앞세우면 알게 됨(+1), 지식과 마음을 **둘 다 뚜렷하게** 앞세우면 0, 그 밖에는 마음(−1). 소재로 나오는 지식은 알게 됨의 근거가 아니다. 형식만 말하는 소개도 정보 없음으로 두지 않는다 | 선 끝에 → 마음 (형식만 소개) / "소설로 읽는 철학사" → 알게 됨 | 🍃 소설·시 중 얻는 것이 정보 없음·0인 책 |
