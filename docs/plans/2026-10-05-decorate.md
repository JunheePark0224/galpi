## 결정

1. **처음 그림은 `saves.original_art` 열 하나 (0005)** — 다른 곳(도감 `first_art`, 이벤트 기록)에서 다시 찾는 것보다 단순하고 확실하다. 마이그레이션이 기존 줄을 `art`로 채우고 `not null`. **트리거가 쓴다**: 새 줄은 `art`를 그대로, 고칠 때는 옛 값을 그대로 — 앱도, anon 키로 직접 부르는 요청도 처음 그림을 바꿀 수 없다. RLS·권한은 0003 그대로(표 단위 권한이 새 열도 덮음). 확인 SQL `web/supabase/checks/decorate_rls.sql`.
2. **0005 전에도 사이트는 돈다**: 읽기는 `original_art`가 없으면(42703) 그 열 없이 다시 읽고 `originalArt: null` → 시트에 [꾸미기]가 나오지 않고, 서버는 503. 처음 그림을 모른 채 꾸미게 두면 나중에 0005가 꾸민 그림을 "처음 그림"으로 채워 버리므로 숨기는 쪽.
3. **고를 수 있는 부분 = 도감에 있는 것 + 그 책갈피의 처음 그림 부분 + 땅 "없음"** (`lib/library/decorate.ts` `partAllowed`, 화면과 서버가 같은 함수). 처음 그림 부분은 로그인 전에 만나 꽂은 책이면 도감에 없을 수 있어서.
4. **서버 확인**: `openLibrary`(같은 사이트·분당 60·본문 2KB·로그인, 키 `decorate`) → `parseArt`(모르는 값 400) → 그 사람의 책인지(404) → 처음 그림을 아는지(503) → 부분마다 `partAllowed`, 도감은 **그 사람의 세션으로** `collection`을 읽음(RLS — 서비스 키 안 씀). 하나라도 아니면 **403**. `rare`는 부분에서 다시 계산. 저장은 라이브러리 저장소(`updateArt`, `art`만).
5. **[처음 그림으로]는 미리 보기만 처음 그림으로** — [이대로 꽂기]가 처음 그림을 보낸다(되돌리기도 같은 길·같은 확인). E-38 `is_reset` = 저장한 그림이 처음 그림과 같은지.
6. **이벤트 이름**: `part_kind`(E-36)가 String이라 배열은 `parts_changed`, 같은 까닭으로 `tiers_changed`. 새 값은 E-07과 같은 `art`(새 그림 전체).
7. 화면은 먼저 바뀌고(막대 위 작은 책갈피·앞면), 서버가 거절하면 되돌린다(옮기기와 같은 `atOnce`).
