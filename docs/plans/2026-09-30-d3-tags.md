# D3 책 태그·첫인상 한 줄 200권 Plan

**Goal:** 선정된 200권(`data/processed/d1_selected.csv`)에 AI 태그 초안과 첫인상 한 줄을 붙이고, 규칙 검사·실제 태그 시뮬레이션을 통과시킨 뒤, 사용자가 걸린 책부터 검수할 화면(D4)을 만든다.

**Spec:** `docs/balance-game.md` 2절 태그 기준 표 · `docs/target-chips.md` 2·4절 · `docs/book-pool.md` 1·2절 · `docs/PHASES.md` D3·D4 · PRD F-08(한 줄), E-07(한 줄 말투)

## Global Constraints

- **YES24 책소개·목차 원문은 git에 올리지 않는다.** 원문을 담은 파일은 `data/processed/check/`(ignore됨)에만. 커밋되는 파일에는 ISBN·우리 태그·우리 한 줄·근거 요약(우리 말, 40자 이내, 원문 문장 복사 금지)만
- 🍃 축 태그는 `balance-game.md` 태그 기준 표 그대로 (+1 / 0 / −1). 이야기가 없는 책(시·에세이·교양)의 세계는 0, 단 상상 세계를 그리는 시·그림책은 −1
- 🎯 주제 = 선정 슬롯(고정), 세부 키워드 = `keyword_tags_draft.json`의 규칙 결과(사람 κ 0.79, AI가 바꾸지 않음), 읽는 방식 = AI (개념 / 실습 / 사례 중 하나)
- 🎯 분야: 데이터 분석·통계 → `데이터·통계` / AI 활용·업무 자동화 → `AI·IT 활용` / 습관·집중·시간·생산성 → `습관·자기계발`. 🎯 `genre` = 주제
- 첫인상 한 줄: 🎯 **요약형**(무엇을 얻는 책인지) · 🍃 **질문형**(물음표로 끝남). 12~36자, 과장어 금지(`check_one_liners.py`의 HYPE_WORDS), 책 제목 반복 금지, 원문 근거가 있어야 함(내용어 1개 이상 겹침), 해요체
- 쪽수는 YES24 값 그대로(`d1_selected.csv` pages)
- D3 완료 기준(PHASES): 한 줄 규칙 통과율 보고, 🍃 축마다 양쪽(+1, −1) 각 25% 이상, 🎯 방식 각 20% 이상, 실제 태그 시뮬레이션 🍃 첫 뽑기 채움 95% 이상·장르 수 3.5 이상. 못 미치면 숫자를 그대로 보고하고 태그를 억지로 바꾸지 않는다

## Tasks

### Task 1: 입력 묶음 만들기 — `src/build_d3_bundles.py`
- `d1_selected.csv` 200권 + `data/raw/yes24/detail/<isbn>.json`(helper: `build_check_page.detail/clean/toc_lines`) → `data/processed/check/d3_bundles/batch_{1..4}.json` (50권씩, 🍃·🎯 섞어 고르게)
- 책마다: isbn, entry, slot, title, author, pages, intro(전체, 공백 정리), toc(최대 60줄), 🎯는 keywords(draft picked)
- 상세가 없는 책은 목록에 `missing_detail`로 표시하고 제목·저자만

### Task 2: AI 태그·한 줄 (서브에이전트 4개 병렬, 묶음 하나씩)
- 입력: 묶음 파일 + 이 계획서의 Global Constraints + `balance-game.md` 태그 기준 표
- 출력: `data/processed/d3/ai_tags_batch_N.json` — `{isbn: {entry, axes?|way?, one_liner, one_liner_style, evidence}}`
- 한 권씩 소개·목차를 읽고 판단. 애매하면 0(🍃) — 억지로 한쪽에 몰지 않는다

### Task 3: 합치기·규칙 검사·실제 태그 시뮬레이션 — `src/build_books_v1.py`, `src/simulate_real.py`
- 네 묶음 합치기 → `data/processed/books_v1_draft.json` (roadmap 3-3 `books` 열: isbn, entry, slot, field, topic, genre, pages, way, axes, keywords, one_liner, one_liner_style) + `data/processed/d3_report.json`
- 검사: 한 줄 규칙(`check_one_liners.check_line`, 근거 재료 = 소개+목차), 🍃 축 분포, 🎯 방식 분포, 200권 모두 있는지, D1 `check` 6권 표시
- `simulate_real.py`: `simulate_draws`의 `draw`·`leaf_score`·사용자 조합을 그대로 쓰고 책만 실제 🍃 100권으로 → 채움·장르 수·겹침·노출 지니 출력, `data/processed/simulate_real.json`
- 걸린 책 목록(`flags`): 한 줄 규칙 실패, `missing_detail`, D1 `check`, 축 4개가 모두 0인 🍃

### Task 4: D4 검수 화면 — `src/build_d4_review.py`
- `data/processed/check/d4_review.html` (로컬 전용, 원문 포함). 걸린 책 먼저, 그다음 나머지
- 책마다: 제목·쪽수·소개(접기)·목차(접기) + AI 태그를 **고칠 수 있는 선택지**(🍃 축 4개 −1/0/+1, 🎯 방식) + 한 줄 수정 칸 + [맞아요]
- localStorage 이어하기, 끝나면 `d4_review.json` 저장 → 사용자가 `data/processed/`에 넣음
- `build_books_v1.py`가 `d4_review.json`이 있으면 반영해 `books_v1.json`(검수본)을 만든다
