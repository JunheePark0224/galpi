# 갈피 구현 로드맵

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 10/16까지 휴대폰에서 도는 갈피(🎯·🍃 입구 → 책 펼치기 → 책갈피 5장 → 궁금해요 책 보기 → 보관·내 서재)를 배포하고, 모든 행동을 기록한다.

**Architecture:** Next.js(App Router) 한 앱 안에 화면과 서버 기능을 둔다. 추천 규칙은 화면과 분리된 순수 함수(`web/src/lib/recommend/`)로 먼저 만들고 100% 테스트한 뒤 화면에 붙인다. YES24 호출·LLM 분류·Amplitude 전달은 서버 라우트에서만 하고, 행동 기록은 `track()` 하나로 Supabase `events`에 쌓는다.

**Tech Stack:** Node 24 · Next.js 16.3 · React 19.3 · TypeScript · Motion 13 · Supabase(supabase-js 2.117, ssr 0.12) · Vitest 5 · Playwright 1.63 · Vercel

**Spec:** `docs/PRD.md` v0.2 · `docs/PHASES.md` v0.1 · `docs/DESIGN.md` v0.1 · `docs/balance-game.md` v0.2 · `docs/target-chips.md` v0.2 · `docs/book-pool.md` v0.1

## Global Constraints

- PRD에 없는 기능은 만들지 않는다. `docs/stitch/exports/README.md`의 "따르지 않을 부분" 11건은 구현하지 않는다
- 추천은 공개된 태그 + 점수 규칙으로만. AI는 직접 쓴 목적을 **우리 주제·키워드 목록 안에서** 분류만 한다
- 키 값은 코드·git·로그·브라우저 번들에 넣지 않는다. YES24·Anthropic·Supabase service role·Amplitude 키는 서버에서만
- 우리 DB에는 ISBN·우리 태그·우리 한 줄·보관·행동 기록만. YES24 책소개·가격·표지는 보여줄 때 불러와 짧게 캐시
- 화면: 모바일 우선, 데스크톱은 가운데 기둥 최대 430px. 누르는 곳 44px 이상. 한 화면에 주 버튼 하나. 다크 모드 없음
- 색·글꼴·움직임 값은 `docs/DESIGN.md` T-01~T-06 그대로. 민음사 책갈피 모양(네모 카드·왼쪽 세로 띠·두 줄 색 띠) 금지
- 바닥 표시 "정보 제공: 예스24 · 예스24와 무관한 개인 프로젝트", 책소개는 문장 단위로만 자른다
- 이벤트는 화면을 만드는 Phase에서 함께 심는다 (PRD 4절 E-01~E-25, 공통 속성 포함)
- 커밋 메시지는 영어 conventional commits (`feat:`, `test:`, `chore:` …)
- Vercel 배포·Supabase 프로젝트 생성·OAuth 앱 등록·키 입력은 **사용자가 직접** 한다

## 1. Phase 진행 절차 (Reference 방식)

모든 Phase는 같은 순서로 간다.

1. Phase 시작 때 상세 계획 파일을 쓴다 (`docs/plans/YYYY-MM-DD-pX-*.md`). P0·P1은 이 로드맵과 함께 작성됨
2. 태스크마다 **구현 서브에이전트 → 스펙 리뷰 → 코드 품질 리뷰**. 문제가 나오면 고치고 다시 리뷰
3. Phase 끝에 `docs/PHASES.md`의 완료 기준을 하나씩 확인 (테스트·타입 검사·린트·빌드·E2E 로그 첨부)
4. `docs/process.md` 기록, `docs/tasks.md` 체크, 작업 브랜치를 `main`에 병합
5. 날짜는 잠정 — 끝나면 바로 다음 Phase

브랜치: `main`(항상 빌드 통과) ← `feat/p0-setup`, `feat/p1-recommend` … Phase마다 하나.

### 3-1. 추천 (P1 → P3·P4)

```ts
// web/src/lib/recommend/types.ts
export type Entry = "leaf" | "target";
export type AxisKey = "temp" | "pull" | "gain" | "world";
export type Tag = -1 | 0 | 1;
export type Way = "개념" | "실습" | "사례";
export type Rng = () => number;               // [0, 1)

export interface LeafBook { id: string; entry: "leaf"; genre: string; pages: number; axes: Record<AxisKey, Tag> }
export interface TargetBook {
  id: string; entry: "target"; field: string; topic: string; genre: string; // genre === topic
  pages: number; way: Way; keywords: string[];
}
export type Book = LeafBook | TargetBook;

export type BalanceChoice = "A" | "B" | "unsure";
export interface LeafAnswers { temp: number; pull: number; gain: number; world: number; len: Tag } // 축 -2..2
export interface TargetAnswers { topic: string; way: Way | null; len: Tag; keywords: string[] }

export interface Pick { book: Book; score: number; kind: "recommended" | "random" }
export interface DrawResult { picks: Pick[]; widened: boolean; exhausted: boolean }
```

// web/src/lib/track/client.ts
export function track(name: EventName, props?: Record<string, unknown>): void;
