- SVG 동물은 `assets/animals/` (100×100, 지금 그림체). 배경·소품은 `BookmarkArt.tsx`처럼 코드로 그린다 — 모양은 `rare-art.html`을 그대로 옮긴다.
- **확률**: 동물·배경·하늘 소품·땅 소품을 **각각 따로** 뽑는다. 각 일반판 90% · 한정판 9% · 초판본 1%, 등급 안에서는 고르게.
  ("없음" 땅 소품은 일반판에 그대로.) 그림은 책과 무관하게 뽑는다 (원칙 2). 돈으로 뽑는 기능 없음 (F-21).
- **초판본 효과** (gif): 창에 금빛 테두리 + 몇 초마다 금빛이 한 번 스침, 동물 = 뒤 금빛 후광(숨 쉬듯) + 반짝이 4개,
  배경 = 금가루가 떠오름, 소품 = 뒤 빛 + 반짝이 2개. 한정판은 효과 없음. 움직임 줄이기 설정이면 테두리·후광만(움직임 없음).
  움직이는 동안(T-03 `moving`)·작은 책갈피(막대 위)에서는 가볍게 (반짝이·금가루 끄고 테두리·후광만 — 성능).
- `ArtCombo.rare`는 남기되 뜻을 정한다: 넷 중 하나라도 한정판 이상이면 true (옛 기록 호환). 새 필드로 등급을 따로 두는 게 낫다면 설계에서 정한다.

## 도감 (사용자 결정)

- **위치: 내 책갈피 안** — 맨 위 [막대 | 도감] 전환 (시안 ①). 로그인 전에는 내 책갈피 대신 도감 칸이 모두 실루엣 + "로그인하면 만난 책갈피가 도감에 모여요" + [로그인하고 모으기] (시안 ②). 머리글 메뉴는 늘리지 않는다.
- **기준: 나온 책갈피** — 책장(S-05)에서 그 책갈피가 보인 순간 기록 (꽂지 않아도). **로그인한 사람만** 기록.
  서버가 그림을 다시 계산해 기록한다 (브라우저가 보낸 그림을 믿지 않는다 — 전설을 꾸며 넣지 못하게).
- 화면: 모은 수 "동물 n / 16 · 배경 n / 11 · 소품 n / 16", [동물 | 배경 | 소품] 탭, 칸 제목 **일반판 · 한정판 · 초판본**(초판본은 금빛 글씨),
  만난 칸 = 처음 만난 그 그림, **못 만난 칸 = 실루엣 + "???"**(초판본도 실루엣), 새로 만난 칸 NEW(도감을 한 번 보면 사라짐),
  맨 아래 확률 공개 "책과는 상관없이 뽑혀요. 돈으로 뽑는 기능은 없어요."
- **처음 만날 때 (시안 ③, 사용자: 너무 튀지 않게, 조금 뒤 사라지게)**: 책갈피 위 작은 배지 "처음 만난 동물!" / "처음 만난 배경!" / "처음 만난 소품!"
  (여럿이면 한 줄로 합침, 등급이 높으면 앞에 등급 — "초판본 · 처음 만난 동물!"), 약 2.5초 뒤 스르르 사라짐. 일반판은 더 작고 조용하게.
  로그인한 사람만 (로그인 전에는 "처음"을 알 수 없으므로 배지 없음).

## 남은 설계 (구현하며 정함 — 설계 문서에 기록)

- 데이터: 사람마다 만난 항목(종류·값·처음 만난 날·처음 그림) — Supabase 마이그레이션 (적용은 사용자가 Supabase에서)
