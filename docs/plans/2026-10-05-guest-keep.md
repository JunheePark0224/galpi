# 로그인 없이 저장 + "내 책갈피에 저장" 문구 (2026-10-05, 사용자 확정)

## 왜

친구 시험: 책이 나왔을 때 [🔖 꽂기]를 **왜 해야 하는지 와닿지 않는다**. 두 가지가 겹쳤다.
1. "꽂기"라는 말이 무엇이 되는지 말해 주지 않는다.
2. 로그인 전이면 누르자마자 로그인 창이 뜬다 — 해 보기 전에 가입부터 요구한다.

사용자 결정 (10-05):
- **A. 로그인 없이 저장**: 이 브라우저에 임시로 모았다가, 로그인하면 계정으로 옮긴다.
- 문구 **B "내 책갈피에 저장"** (A "저장하기" / C "찜하기" 비교 시안에서 선택).
- 시안 ①②③ (`scratchpad/deco/keep.png`) 승인: ① 넓은 가죽 버튼 ② 책갈피가 오른쪽 위 "내 책갈피"로 날아가 +1, 토스트 "보러 가기" ③ 로그인 전 내 책갈피 + 안내.
- 도감·꾸미기·막대 정리는 그대로 로그인 전용.

## 화면

### S-06 저장 버튼 (DESIGN C-16b 교체)
- 자리: 제목·저자 **아래**, [예스24에서 보기] **위**. 가로 꽉 찬 가죽 버튼(C-26 [책갈피 옮기기]와 같은 결: `--cloth` 바탕, 금박 글씨 `--foil`, 2px `--edge` 안쪽 테두리, 12px 모서리), 높이 ≥ 48px.
- 누르기 전: 첫 줄 **"🔖 내 책갈피에 저장"**, 둘째 줄 작은 글씨 **"나중에 다시 꺼내 볼 수 있어요"**.
- 저장한 뒤: 초록(`--green` 계열, 기존 성공 색) 버튼 **"✓ 내 책갈피에 저장했어요"** + 작은 글씨 **"다시 누르면 빼요"**. 다시 누르면 뺀다(E-16).
- 주 버튼은 그대로 [예스24에서 보기] (잉크 알약). 제목 옆 작은 알약 [🔖 꽂기]는 없앤다.
- 처음 S-06 안내(C-21) 문구: "🔖 내 책갈피에 저장해 두면 나중에 다시 볼 수 있어요".
- 실패: "저장하지 못했어요. 다시 눌러 주세요."

### 저장하는 순간 (로그인 전·후 같음)
- 표지 위 빼꼼 책갈피 모양의 작은 복제본이 오른쪽 위 헤더의 "내 책갈피"로 날아간다(약 600ms, 곡선). 도착하면 헤더 숫자 옆에 "+1" 작은 배지가 1.5초.
- 아래 토스트: "내 책갈피에 저장했어요 · **보러 가기 →**"(/library 링크), 4초 뒤 사라짐.
- `prefers-reduced-motion`: 날아가기 없이 배지·토스트만.

### 헤더 (AccountButton)
- 로그인: 지금처럼 [내 책갈피 N].
- 로그인 전 + 임시 책갈피 ≥ 1: **[내 책갈피 N]** (→ /library). 0이면 지금처럼 [로그인].

### S-09 로그인 전 내 책갈피 (/library)
- 임시 책갈피가 있으면: 제목 "내 책갈피" → 안내 상자
  - 굵게 "지금은 이 브라우저에만 저장돼 있어요"
  - "로그인하면 사라지지 않고 휴대폰·PC 어디서나 이어져요. 막대로 정리하고, 도감을 모으고, 책갈피를 꾸밀 수도 있어요."
  - 버튼 [로그인하고 지키기] → S-07 로그인 시트 (source `library`)
- 그 아래 "첫 막대"에 임시 책갈피들(기존 막대·책갈피 그림 재사용, 옮기기·꾸미기 없음). 누르면 크게 보기 시트: [예스24에서 보기]와 [빼기]만.
- 맨 아래 작은 글씨: "브라우저 기록을 지우면 임시 책갈피도 사라져요".
- 그 아래 지금의 로그인 전 도감(실루엣) 그대로.
- 임시 책갈피가 없으면 지금 화면 그대로.

## 동작

- 임시 저장소: `localStorage` 키 `galpi.guestSaves`, `{ v: 1, items: SaveInput[] }`(isbn·art·reason·metOn — 지금 pending과 같은 모양, 같은 검증 parseArt/parseReason). 같은 책은 하나. **최대 100권** — 넘으면 저장하지 않고 "임시 책갈피는 100개까지예요. 로그인하면 계속 모을 수 있어요".
- 저장소가 막힌 브라우저(사생활 모드 등): 지금처럼 로그인 시트를 연다(source `save`) — 버튼이 아무 일도 안 하는 일은 없게.
- 로그인 뒤 옮기기: 로그인 상태가 확인되면(LoginReturn) 임시 책갈피가 있으면 하나씩 `POST /api/library/saves`로 보낸다. 성공한 것(이미 있던 책 포함)은 임시 목록에서 지우고, 실패한 것은 남겨 다음 방문에 다시. 새로 들어간 수만큼 헤더 숫자 +. E-39 한 번. 각 책마다 E-15를 다시 남기지 않는다(이미 저장 때 남김).
- 지금의 "로그인 기다리는 책갈피"(pending, sessionStorage)와 로그인 뒤 자동 꽂기(keepWaiting)는 임시 저장소로 대신한다 → pending 모듈은 없앤다.
- 빼기: 로그인이면 `DELETE /api/library/saves`(지금 S-09 빼기와 같은 길) + 헤더 −1, 로그인 전이면 임시 목록에서 지움. 둘 다 E-16.
