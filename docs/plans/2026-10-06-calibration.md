# 라벨 정의 v3 · 정답 세트 · 맞춰 보기 (2026-10-06, 사용자 승인)

## 왜
정의를 고치면서 동시에 검수하니 기준이 움직여 검수가 끝나지 않는다(10-06 사용자). 두 AI끼리의 일치는 정확도가 아니다
(10-06 신호 기준 재태그: 온도는 좋아졌지만 세계는 AI-2가 "해당 없음 0"을 잘못 써서 나빠짐, 끌림은 사람 답이 새 기준보다 먼저 붙어 어긋남).
→ **정의를 먼저 굳히고(사람이 판단 → 규칙·예시), 정답 세트로 AI 정확도를 잰 뒤, 같은 기준으로 서재 전체를 다시 태그**한다.

## 일정 (사용자 10-06)

- 수(10-07): 정의서 확정 → 기존 책 다시 태그 → 1,000권 · 마지막 웹 점검 · 마케팅 전략
- 목(10-08): 링크 올리고 홍보

## 단계
1. **정의서 v3** `docs/label-dictionary.md` — 🍃 축 4개(온도·끌림·얻는 것·세계)와 🍃 장르 13개·🎯 주제 16개·키워드·방식의 **판단 순서**(1번 신호 → 2번 …), 값마다 조건, 예시, '정보 없음' 조건, 흔한 실수. 지금까지의 사용자 결정을 모두 모은다(아래 "들어가는 결정"). 원본 문서(balance-game 2절, book-pool 1-3, target-chips)는 정의서와 같은 말로 맞추고, 태거는 정의서를 읽는다.
2. **정답 세트 40권** — 서재(books.json)와 2026-10-05-2에서 🍃 장르별·🎯 주제별로 고르게(🍃 약 28, 🎯 약 12), 소설·비소설·애매한 경계 책을 섞는다. 이미 사용자가 검수한 11권은 넣되, v3 기준으로 다시 라벨한다.
3. **정답 라벨 페이지** — AI 답을 **숨기고** 책 소개·목차 + 정의서(해당 축 부분)를 옆에 보여 준다. 축마다 값 + 근거 신호 한 줄(선택) + '정보 없음'. 결과는 내려받기 → `data/processed/check/gold/gold-v3.json`(git 밖, YES24 글 없음).
4. **맞춰 보기** — 정답 세트를 지금 정의서로 두 패스 태그(1번에 약 $0.8), 축·장르·주제별로 **AI-1·AI-2 각각의 정답 일치율**과 틀린 책 목록(두 AI의 근거 한 줄 + 사람 답)을 보여 주는 페이지. 틀린 책마다 사람이 고른다: AI가 틀림 → 정의 문구 / 내 답이 틀림 → 정답 수정 / 기준에 빈칸 → 규칙 추가. 목표: **축·장르·주제마다 90% 이상**. 넘으면 v3 확정.
5. **서재 전체 다시 태그** — 정의서 버전(`rules_version: "v3"`)을 책마다 남긴다. 사람에게는 두 AI가 갈린 축·'정보 없음'·한 줄 규칙 걸림 + 표본 10%만. 이미 사람이 검수한 값과 v3 AI 값이 다른 책은 따로 묶어 보여 준다(한 기준으로 맞추기 위해).
6. **1,000권** — v3로 새 묶음, 걸린 책 + 표본만 검수. 정답 세트 일치율이 유지되면 표본 비율을 낮춘다.

- 10-05: 세계 축 — 현실 배경 소설은 현실, 0은 정말 섞였을 때만 / 장르 경계 1-3 (내용 장르 우선·중심 줄기·동점 순서·로맨스) / 한 줄 🍃 질문형·🎯 요약형
- 10-06 오전: 얻는 것 0 (→ 오후에 "정말 반반일 때만, 둘 다 약하면 더 강한 쪽"으로 바뀜) / 선집 A안(편 수로 절반) / 장르는 한 권에 하나
- 10-06 신호 기준 (`plans/2026-10-06-label-signals.md`): 원칙 0, 온도 신호표(비소설은 끝맺음·어조 두 신호), 끌림(끄는 힘의 종류), 얻는 것 신호표, 넥서스 예시, 마케팅에 영업·협상, 리더십↔직장 생활은 독자로, '확인 필요' = 두 AI가 다르거나 정보 없음
