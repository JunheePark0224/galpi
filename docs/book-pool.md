## 2. 뽑기 규칙

| 단계 | 규칙 | 이유 |
|---|---|---|
| ① 후보 | 이번 세션에서 이미 본 책은 제외 | 다시 뽑기에서 같은 책이 안 나오게 |
| ② 점수 | `balance-game.md` 3절 / `target-chips.md` 4절 | 기준 공개 |
| ③ 상위권 | 최고 점수에서 **Δ = 2점 안쪽**의 책만 후보 | 관련 없는 책이 끼지 않게 |
| ④ 가중 추첨 | 상위권에서 **점수가 높을수록 잘 뽑히게** 무작위 추첨 (확률 ∝ e^(점수/τ)) | 같은 답이라도 매번 조금씩 다른 책 → 새로움 |
| ⑤ 장르 상한 | 한 번의 5권 중 같은 장르 **최대 2권** | 다양성 |
| ⑥ 넓히기 | 4권이 안 차면 Δ를 1씩 넓힌다 | 막다른 길 없음 |
| ⑦ 무작위 1권 | 🍃 전체 / 🎯 같은 분야에서 균등 추첨, 장르 상한 지킴, 자리 무작위 | 검증용 (겉모습 동일) |
| ⑧ 바닥 알림 | 🎯에서 조건에 맞는 책이 떨어지면 첫 장에 **"조건에 딱 맞는 책은 여기까지예요"** + ~~[조건 하나 풀기] [같은 분야 다른 주제]~~ | 솔직하게 — 조용히 엉뚱한 책을 채우지 않는다. **두 버튼은 만들지 않는다(10-01, P4)** — PRD F-05에 없고, 조건 풀기는 첫 장 [한 번 고치기], 같은 조건의 새 책은 S-08 [다시 뽑기]가 맡는다 |

**설정값**: 🍃 τ = 1.0 (새로움 쪽), 🎯 τ = 0.5 (정확도 쪽), 둘 다 Δ = 2.

## 3. 시뮬레이션 결과 (가상 태그, 모든 답 조합)

🍃 답 조합 1,875가지, 🎯 조합 288가지. 각 조합이 다시 뽑기를 6번까지 해 본다.

| 뽑기 방식 | 첫 뽑기 채움 | 좋은 뽑기 횟수 | 4번 이상 좋음 | 5권 중 장르 수 | 같은 답 두 사람 겹침 | 안 나오는 책 |
|---|---|---|---|---|---|---|
| 🍃 점수 순서대로 (τ=0) | 99.9% | 4.0 | 59% | 3.9 | 0.58 | 0 |
| 🍃 τ=0.5 | 99.0% | 3.7 | 52% | 3.9 | 0.39 | 0 |
| **🍃 τ=1.0 (채택)** | **97.4%** | **3.5** | **48%** | **3.9** | **0.26** | **0** |
| 🍃 τ=2.0 | 90.7% | 2.7 | 35% | 3.9 | 0.14 | 0 |
| 🎯 100권(주제당 16~17), τ=0.5 | 91.7% | 1.3 | 1% | — | 0.54 | 0 |
| 🎯 150권(주제당 25), τ=0.5 | 92.0% | 2.1 | 11% | — | 0.50 | 0 |

- **좋은 뽑기** = 추천 4권의 평균 점수가 그 사람이 받을 수 있는 최고 점수의 절반 이상 (아무 조건도 고르지 않은 사람은 이 지표에서 제외). **첫 뽑기 채움** = 추천 4권이 모두 0점보다 높음
- **겹침**: 같은 답을 한 두 사람의 추천 4권이 얼마나 같은가(0 = 전부 다름, 1 = 전부 같음). τ=1.0이면 약 1권만 겹친다

### 읽는 법
1. **🍃 100권은 충분하다.** 첫 뽑기는 97%가 채워지고, 평균 3.5번까지 좋은 뽑기가 이어진다. 5권 중 장르가 평균 4개로 다양하고, 안 나오는 책이 없다
2. **τ=1.0을 고른 이유**: 점수 순서대로(τ=0)면 같은 답에 거의 같은 책(겹침 0.58) → 친구끼리 해 보면 "똑같네"가 된다. τ=1.0은 정확도를 조금 내주고(99.9 → 97.4%) 새로움을 크게 얻는다. τ=2.0부터는 정확도가 눈에 띄게 떨어진다
3. **🎯가 약한 곳이다.** 주제당 16~17권이면 조건(수준·방식·분량)을 고른 사람에게 딱 맞는 책은 1~2번 뽑기면 바닥난다. 그래서 → ⑧ 바닥 알림을 넣고, **배포 후 늘리는 책은 🎯부터**(주제당 25권이면 좋은 뽑기 1.3 → 2.1). 🎯 무작위 1권을 같은 분야 전체에서 뽑든 다른 주제에서만 뽑든 차이는 ±0.1회로 작아서 설계대로(같은 분야) 둔다
4. 🎯는 목적이 분명한 사람이라 다시 뽑기를 여러 번 하기보다 딱 맞는 몇 권이 중요하다 — τ를 낮게(0.5) 둔다
