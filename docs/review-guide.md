# 검수 기준 모음 — 새 책 검수 페이지에서 보는 것 전부 (2026-10-05)

검수 페이지(`data/processed/check/pipeline/<묶음>.html`)에서 책 한 권을 볼 때 판단하는 기준을 한곳에 모은 **요약본**이다.
이 문서는 **원본이 아니다** — 값이 다르면 각 절 끝의 원본이 맞다. 원본에서 찾지 못한 것은 "—".
책소개·목차 글은 이 문서에 옮기지 않는다(예스24 글). 책은 제목만 적는다.

## 0. 한눈에 — 카드 하나를 보는 순서 (10-05 개편)

| 순서 | 볼 곳 | 질문 |
|---|---|---|
| 1 | 묶음 제목 (①~④) | 왜 이 책이 내 앞에 왔나? (6절) |
| 2 | 책소개 · 목차 | **이 칸으로 찾아온 사람에게 이 책을 줘도 되나?** (1절) |
| 3 | "정할 것 n개"의 질문들 | ① 넣을지(1절) · ② 다르게 본 칸 — 축(3절)·키워드·방식(4절) · ③ 한 줄(5절) |
| 4 | "같게 본 칸" 한 줄 | 눈에 띄게 틀린 게 있으면 "같게 본 칸도 고치기" (갈래가 틀렸으면 거기서 **다른 갈래로**, 2-3절) |
| 5 | [확인] | 질문을 다 고르면 켜진다 |

- 다 보면 맨 아래 **검수 결과 내려받기** → Claude에게 알린다 (HANDOFF 3절, 8절 참고).
- 근거 메모, AI-1 확신처럼 앱에 나가지 않는 것은 묻지 않는다 (6-1절).
- **검수에서 안 보는 것**: 분량(얇음 ≤ 280쪽 / 두꺼움 ≥ 380쪽, 그 사이 0)은 태그가 아니라 예스24 쪽수로 자동 계산한다. 책 점수·뽑기도 사람이 정하지 않는다.

## 1. 이 책이 갈피에 맞나 (넣기 / 빼기)

**판단 질문 하나**: 이 칸(🎯 주제 또는 🍃 장르)으로 찾아온 사람에게 이 책을 줘도 되나?
AI의 "맞음 예/아니요"도 같은 질문이다 — **그 주제·장르 전체**에 맞는지만 본다. 어떤 키워드를 찾다 나왔는지, 단어 규칙 후보와 다른지는 "맞음"에 넣지 않는다(키워드는 따로 고른다).

| 상황 | 판단 |
|---|---|
| 칸의 정의에 들어맞는다 | 넣기 |
| 칸의 "넣지 않는 것"(아래 표)에 해당한다 | **빼기** |
| 칸은 틀렸지만 다른 칸에는 맞는다 | 빼지 말고 **다른 갈래로 (다시 태그)** — 책을 잃지 않는다 |
| 같은 갈래 안에서 다른 장르·주제가 맞다 | 장르/주제 선택 상자를 바꾼다 (결정은 넣기 그대로) |
| 정말 판단이 안 선다 | 대기 (7절) |

**갈피가 일부러 다루지 않는 것** (원칙 0: 읽을 책이 정해지지 않은 사람이 맞는 책을 재미있게 만나는 용도) — 보이면 빼기:

| 안 다루는 것 | 이유 |
|---|---|
| 수험서 | 이미 읽을 책이 정해진 사람의 영역 (예스24 규칙에서도 제외) |
| 어린이 책 | 갈피 이용자(읽을 책을 모르는 성인)가 아님 |
| 만화 · 웹소설 · 종교 | 형식·플랫폼·목적이 다름 (이 셋을 제외한다는 명시 문서는 확인하지 못함 — "—", 원칙 0 적용) |
| 이미 아는 책·작가 찾기, 리뷰, 구매, 독서 기록, AI 상담 | 갈피가 하지 않는 일 |

**주제별로 "넣지 않는 것"** (사용자 확정 10-05 포함):

| 주제 | 넣지 않는 것 |
|---|---|
| 마케팅·브랜딩 | 광고 자격증·수험서, 특정 플랫폼 조작 요령만 있는 책 |
| 리더십 | 위인전·정치인 자서전 |
| 건강·운동 | 의학 전문서·질병 치료서·다이어트 비법서 |
| 요리·살림 | 전문 조리사 교재, 사진 위주 레시피 화보집만인 책 |
| 취업·커리어(자소서·면접) | 수험서 |
| AI 활용 · 통계 · 데이터 분석 | 교사·학교·투자·영상 편집용(AI 활용) / 수능·교과(통계) — `genres.md` 요약 |
| 🍃 한국·외국 소설 | 추리·SF·판타지 색이 짙은 책(내용 장르로) |
| 🍃 시 · 인문 · 과학 교양 · 예술·여행 | 희곡·철학(시) / 명리·주역·풍수·사주(인문) / 교과·문제집(과학 교양) / 화보·가이드북·지도(예술·여행) |

### 2-3. 언제 "다른 갈래로 (다시 태그)"를 쓰나 (🎯 ↔ 🍃)

| 상황 | 쓰는 것 |
|---|---|
| 🎯로 왔지만 사실 **이야기·교양 책**이다 (예: 『뇌』 모기 겐이치로 → 🍃 과학 교양) | 결정 "다른 갈래로" → 🍃 장르를 **반드시** 고른다 |
| 🍃로 왔지만 사실 **방법을 알려 주는 책**이다 | 결정 "다른 갈래로" → 🎯 주제를 고르거나 "AI가 정해요"(파이프라인이 우리 규칙으로 가장 맞는 주제를 고름) |
| 🍃 안에서 장르만 다르다 (예: 한국 소설 → 로맨스) | 갈래는 그대로, **장르 선택 상자**만 바꾼다 (다시 태그 아님) |
| 🎯 안에서 주제만 다르다 | **주제 선택 상자**만 바꾼다 (바꾸면 키워드가 비워지니 다시 고른다) |

🎯 ↔ 🍃 판단에 쓰는 기준 (2-2절 경계에서):
- 마음을 돌보는 **방법**을 주면 🎯 마음 돌보기, **작가의 이야기**로 위로하면 🍃 에세이.
- 뇌과학 지식 자체를 **교양**으로 다루면 🍃 과학 교양, 뇌로 습관·집중을 **고치는 법**이면 🎯 습관·집중(뇌과학).
- 퇴사 경험담 에세이는 🍃 에세이, 퇴사 결정·준비를 다루면 🎯 취업·커리어(이직·퇴사).
- 주의: 다시 태그된 책은 **빼기와 달리 잃지 않고** 다음 묶음에서 맨 먼저 새 갈래로 다시 태그된다(`requeue.json`).

## 3. 🍃 이야기 축 네 개

책마다 축 4개에 **+1 / 0 / −1**. 애매하면 0 — 단 **세계는 중간(0) 조건일 때만 0**. 한 줄 가르는 질문에 답하면 된다.
페이지의 세 칸 버튼 이름이 아래 표의 "+ / 중간 / −" 칸이다. 각 칸에는 AI-1·AI-2가 고른 쪽이 작게 표시된다.

| 축 (페이지 이름) | + | 0 (중간) | − |
|---|---|---|---|
| 온도 (책을 덮은 뒤 남는 느낌) | 따뜻함 | 중간 | 여운·서늘함 |
| 끌림 (끌리는 힘) | 문장 | 중간 (둘 다 강하면) | 몰입·이야기 |
| 얻는 것 (읽고 나서 얻는 것) | 알게 됨 | 중간 | 마음 |
| 세계 (책 속 세상) | 현실 | 중간 (정말 섞였을 때만) | 딴 세상 |

### 온도
- **가르는 질문**: 마음이 데워지는 책인가, 오래 먹먹하고 서늘하게 남는 책인가.
- 예 — 소개하는 말이 "마음이 따뜻해졌어"면 +, "한동안 멍했어"면 −. 둘 다 아니거나 반반이면 0. (원본에 제목 예시 —)
- 흔한 실수: 슬픈 내용 = 무조건 −로 보기. 슬퍼도 읽고 나서 마음이 데워지면 +. 기준은 **내용이 아니라 덮은 뒤 남는 느낌**.

### 끌림
- **가르는 질문**: 계속 읽게 만드는 게 **문장 자체**(음미·밑줄)인가, **다음이 궁금한 전개**(손에서 못 놓음)인가.
- 판별법: 소개할 때 "이 문장 좀 봐"면 문장(+), "앉은 자리에서 다 읽었어"면 몰입(−). **둘 다 강하면 0.**
- 비소설: 글맛이면 문장(+), 사례·이야기로 술술 읽히면 몰입(−).
- 흔한 실수: 시·에세이는 무조건 문장, 추리는 무조건 몰입으로 찍기. 책마다 질문에 다시 답한다. (원본에 제목 예시 —)

### 얻는 것
- **가르는 질문**: 새로 아는 게 생기는 책인가, 마음이 달라지는 책인가.
- 알게 됨(+) = 읽고 나서 누군가에게 알려주고 싶은 쪽, 마음(−) = 조용히 곱씹는 쪽. 둘 다 아니면 0. (원본에 제목 예시 —)
- 흔한 실수: 비소설이니까 무조건 알게 됨(+). 삶의 태도를 바꾸는 인문서는 마음일 수 있다.

### 세계
- **가르는 질문**: 실제로 있을 수 있는 세계인가, 여기 없는 세계를 만든 책인가.

| 값 | 기준 | 예 |
|---|---|---|
| **현실 +1** | 실제로 있을 수 있는 세계 — 사람·삶·사회를 다루는 책. **현실 세계를 배경으로 한 소설은 형식이 철학적이거나 실험적이어도 현실.** 사람·삶·사회·경험이 중심인 비소설(에세이·여행·인문 등)도 현실 | 카렐 차페크 『평범한 인생』 |
| **딴 세상 −1** | 현실에 없는 세계를 만든 책 — SF·판타지·상상 세계, 상상 세계를 그리는 시·그림책 | — |
| **중간 0** | 현실과 비현실이 **정말 섞여** 어느 쪽으로도 가를 수 없을 때만. 또는 사람도 세계도 없는 책 | 톨스토이 우화집(악마·정령이 나오는 우화), 방법만 담은 실용서 |

- **흔한 실수**: 현실 배경 소설인데 "문학적이다/철학적이다/실험적이다"는 이유로 0을 준다 → **틀림. 현실(+1).** 소설이 문학적·철학적이라는 이유만으로 0을 주지 않는다 (10-05 사용자 결정).
- 삶을 다룬 에세이도 현실(+1) (09-30 D4 검수).
- 0은 "잘 모르겠다"가 아니라 **정말 섞였을 때** 쓰는 칸이다.

## 4. 🎯 배우기 — 주제, 키워드, 방식

### 4-1. 주제
주제는 책마다 1개, **일치 필수**(그 주제 책 안에서만 뽑힌다). 경계는 2-2절. 주제는 책이 10권 이상일 때만 이용자에게 켜진다 — 검수에서는 상관없다.

### 4-2. 키워드 — 어떻게 붙이나
- 목록은 **닫힌 목록**(페이지에 보이는 이름만). 없는 말을 지어내지 않는다.
- **책의 중심일 때만** 붙인다. AI는 0~3개, 사람은 최대 5개까지. 스치듯 나오는 말에는 붙이지 않는다.
- 단어 규칙(제목·소개에 그 말이 있다)이 찾은 건 **힌트**일 뿐이다.
- 책의 중심이 목록에 없으면 **후보 칸**(12자 이내 짧은 이름)에 적는다. 같은 후보가 5권 이상 모이면 키워드로 만들지 사용자에게 묻는다.
- 키워드 칩에 마우스를 올리면 뜻이 보이고, "키워드 뜻 보기"를 열면 그 주제 키워드 뜻 전체가 보인다.
- 키워드 목록 설계 기준(검수 때 판단하지는 않음): 키워드 하나에 책 5권 이상, 주제 책의 60% 이하. 너무 흔한 말은 책을 가르지 못해서 목록에서 뺐다.

| 건강·운동 | 운동 습관 | 운동을 시작하고 꾸준히 이어 가는 법(홈트·매일 운동). 운동이 아닌 습관 일반이면 습관·집중(습관) |
| | 달리기·근력 | 달리기·러닝·근력 운동을 제대로 하는 법 |
| | 잠·회복 | 잘 자고 피로에서 회복하는 몸의 습관(수면·휴식). 지침·소진을 마음의 문제로 다루면 마음 돌보기(번아웃·스트레스) |
| 요리·살림 | 집밥 | 집에서 밥·반찬을 해 먹는 기초 요리. 전문 조리사 교재·사진 위주 화보집만이면 넣지 않음 |
| | 정리·미니멀 | 물건을 비우고 정리·수납하는 법(미니멀 라이프) |
| | 살림 기술 | 청소·빨래 등 집을 돌보는 요령. 가계부·돈 모으기면 돈 관리·투자(재테크 기초) |

- 키워드가 하나도 안 맞는 책도 있다(키워드 0개 가능). 억지로 붙이지 않는다.

### 4-4. 방식 (way) — 개념 / 실습 / 사례

**책 안에 연습 문제가 있나가 아니라, 책을 덮었을 때 독자 손에 남는 것**으로 정한다.

| 방식 (페이지 표시) | 남는 것 | 목차 모양 | 예 |
|---|---|---|---|
| **실습** (따라 하며 실습) | **바로 해 볼 방법**(무엇을·어떻게). 연습 문제가 없는 방법서도 실습 | "~하는 법", "~하기", 단계·팁 | 말투 고치는 법, 면접 답변 만드는 법, 가계부 쓰는 법 |
| **개념** (개념부터 쉽게) | **이해**(그게 무엇이고 왜 그런지) | "~란 무엇인가", "왜 ~할까", 원리·이론 | 감정은 어떻게 만들어지는가, 금리가 오르면 생기는 일 |
| **사례** (사례로 술술) | **이야기**(누가 어떻게 겪었나) | 사람·사건·경험담이 뼈대 | 직업 에세이, 투자 성공·실패 이야기 |

- **헷갈리면 질문 하나**: "이 책을 읽고 내일 바로 해 볼 게 생기나?" → 생기면 **실습**, 이해만 깊어지면 **개념**, 이야기로 남으면 **사례**.
- 방식은 책마다 **하나**만 고른다.
- 흔한 실수: 예제가 많으니 실습 / 사례가 몇 개 나오니 사례. 기준은 덮은 뒤 남는 것.

원본: `target-chips.md` 1-2절("읽는 방식 태그 기준") · 2절(키워드 기준) · 2-1절(주제·키워드·정의·경계) · `prompt.py` `MAX_KEYWORDS`

## 5. 한 줄 (첫인상 한 줄)

책갈피에 들어가는 한 줄. 페이지 "한 줄" 칸을 직접 고칠 수 있고, 아래에 **글자 수와 빨간 글씨**가 바로 뜬다.

### 5-1. 규칙 표

| 규칙 | 기준 | 페이지 표시 |
|---|---|---|
| 형태 🍃 | **질문형** — 반드시 `?`로 끝난다 | "질문형은 ?로 끝나요" |
| 형태 🎯 | **요약형** — 이 책으로 무엇을 얻는지 한 문장, **물음표 없음** | "요약형에 물음표" |
| 길이 | 공백을 뺀 글자 수 **12~36자** | "짧음" / "김" |
| 말투 | 해요체 | (페이지 검사 없음 — 눈으로) |
| 과장어 | 아래 목록의 말이 들어가면 안 된다 | "과장: …" |
| 제목 반복 | 책 제목(`:` `=` `(` 앞까지)이 한 줄에 그대로 들어 있으면 안 된다. 제목이 4자 이상일 때만 | "제목 반복" |
| 결말·반전 | 말하지 않는다 | (눈으로) |
| 근거 | 내용어 **2개 이상**이 책소개·목차에 실제로 나오는 말이어야 한다 (지어낸 말 방지) | 규칙 검사에서만 — 걸리면 "왜 보나"에 "근거 약함(겹치는 단어 n개)" |
| 베끼기 | 책소개·목차와 **10글자 이상 이어서 같으면**(공백 무시) 우리 말이 아님 | "한 줄이 책소개를 베낌" — 걸린 한 줄은 저장되지 않고 **빈칸**으로 온다 |

### 5-2. 과장어 목록과 예외

| 막는 말 (포함되면 걸림) |
|---|
| 최고 · 필독 · 반드시 · 완벽 · 인생책 · 미친 · 역대급 · 무조건 · 1위 · 베스트셀러 · 강력 추천 · 꼭 읽어야 |

| 예외 (이 단어 안에 들어 있는 건 봐준다) | 뜻 |
|---|---|
| 완벽주의 · 최고경영자 · 최고점 · 최고치 | 그냥 쓰는 낱말인데 과장어를 포함할 뿐이라 먼저 빼고 검사한다 (10-03: "완벽주의"가 "완벽"으로 걸려서 추가) |

- 목록에 없는 과장도 눈으로 거른다. 기준은 원칙 4 "과장하지 않는다".
- 제목 반복은 4자 미만 제목에는 적용하지 않는다(예: 『생산성』 같은 흔한 낱말은 제목이 아니라 낱말로 본다).

### 5-3. 좋은 예 / 나쁜 예

원본(소스)에는 실제 한 줄 예문이 없다 — "—". 아래는 **규칙을 보여 주려고 만든 설명용 문장**이다(실제 책 한 줄 아님).

| 구분 | 설명용 문장 | 이유 |
|---|---|---|
| 🍃 좋음 | "비 오는 날 혼자 펼치고 싶은 책일까요?" | 질문형, `?`로 끝남, 12자 이상, 과장 없음 |
| 🍃 나쁨 | "비 오는 날 읽기 좋은 책이에요." | 질문형인데 `?`로 끝나지 않음 |
| 🎯 좋음 | "엑셀 함수로 데이터를 정리하는 순서를 익혀요." | 요약형, 물음표 없음, 무엇을 얻는지 한 문장 (소개에 실제로 나온 말이어야 근거 통과) |
| 🎯 나쁨 | "이 책 하나면 데이터 분석이 완벽해져요." | 과장어("완벽") + 근거가 약할 수 있음 |
| 나쁨 | 책 제목을 그대로 넣은 문장 | 제목 반복 — 제목은 책갈피에 이미 있다 |
| 나쁨 | 책소개 문장을 옮겨 쓴 한 줄 | 10글자 이상 이어서 같으면 베끼기 |
| 나쁨 | "반전이 있는 결말이 충격이에요" | 결말·반전을 말함 |

한 줄을 고칠 때: 소개·목차에 있는 **단어**는 쓰되 **문장**은 옮기지 않는다.

원본: `check_one_liners.py`(`MIN_LEN` `MAX_LEN` `HYPE_WORDS` `HYPE_OK` `TITLE_MIN` 근거 규칙) · `checks.py`(`rule_issues` 형태·베끼기 `COPY_RUN=10`) · `prompt.py` `TAG_RULES` one_liner · `review_page.py`·`build_pilot_review.py` `COMMON`(페이지 검사)

## 6. 검수 페이지 읽는 법 (10-05 개편: 사람이 정해야 하는 것만)

### 6-1. 무엇을 묻고 무엇을 안 묻나

| 묻는 것 | 왜 사람이 | 자동화와의 관계 |
|---|---|---|
| ① **넣을지** — 한 AI라도 "이 칸에 안 맞아요" | 맞지 않는 책이 들어가면 이용자에게 바로 보인다 | 두 AI가 갈린 답의 정답 = 기준을 다듬는 재료 |
| ② **두 AI가 다르게 본 칸**만 (온도·끌림·얻는 것·세계 / 키워드·방식) | 정답이 하나여야 추천 점수가 선다 | 어느 칸이 자주 갈리는지 → 그 칸 정의를 고친다 |
| ③ **규칙에 걸린 한 줄** (짧음·김·과장·제목 반복·근거 약함·물음표·책소개 베낌) | 한 줄은 이용자에게 그대로 보인다 | — |
| ④ **표본** — 두 AI가 같게 본 책 중 10% | 같게 봐도 틀리는지 재야 사람 없이 넣어도 되는지 안다 | 졸업 기준(일치 95% 3회 + 표본 10권 이상에서 바뀐 책 5% 이하) |

| 안 묻는 것 (기록에만 남음) | 이유 |
|---|---|
| 근거 없음 / 근거 김 / 근거가 책소개를 베낌 / 판단 이유가 책소개를 베낌 | AI가 남긴 메모. 앱에 안 나가고, 베낀 메모는 이미 지워져 저장된다 |
| AI-1 확신이 낮아요 (두 AI가 모든 칸을 같게 봤을 때) | 같게 본 책이 맞는지는 ④ 표본이 잰다 |

### 6-2. 카드

- **정할 것 n개** — 이 카드에서 고를 질문 수. 질문마다 선택지에 `AI-1` `AI-2` 표시가 붙고, 미리 골라져 있지 않다.
- **같게 본 칸** — 두 AI가 같게 본 태그 한 줄 요약. 틀렸으면 "같게 본 칸도 고치기"를 연다(대기·다른 갈래로 결정도 여기).
- **확인** — 질문을 다 고르면 켜진다(한 줄 질문은 규칙을 통과하면 끝).
- 한 줄이 비어 있으면 책소개를 베껴서 지운 것 — 새로 쓴다.

원본: `review_page.py` · `checks.py`(`needs_person` `decide`) · `review.py` `needs_look`·`--resort` · `sample.py` `trial_sample` · `config.json` `sample_rate`

### 6-3. 표본과 예비(대기)

| | 뜻 |
|---|---|
| **표본** | 시험 기간에는 두 AI가 같게 본 책 중 일정 비율(`sample_rate` 지금 10%)이 검수 페이지에 섞여 온다(표본 배지). 주간 표본 검수면 뽑힌 책 전부. 사람이 본 책으로만 일치율을 계산하고, 안 본 책은 따로 센다. 고쳐진 표본 비율이 "두 AI가 같아도 틀리는 정도"다 |
| **예비 = 대기 (`reserve`)** | 페이지 문구는 "대기". 앱(books.json)에 **넣지 않고** 일단 보류한 책. 한 줄 규칙 걸림, 또는 자동 병합 상태에서 AI가 서로 다른 책이 이 상태로 온다. 일치율 계산에서도 빠진다 |

원본: `review_page.py` `FLAG` · `checks.py`(`rule_issues` `disagreements` `decide`) · `build_pilot_review.py` `LOW_CONFIDENCE = 0.7` · `review.py` `needs_look`·`trial_sample` · `config.json` `sample_rate`

## 7. 결정 버튼

### 7-1. 카드의 버튼

| 버튼/칸 | 하는 일 |
|---|---|
| ① 맞아요 · 넣기 / 안 맞아요 · 빼기 | 이 칸에 맞는 책인가 (AI-2가 안 맞다고 본 이유가 옆에 보인다) |
| ② 축 세 칸 · 키워드 칩 · 방식 | 갈린 칸만. 선택지에 AI-1·AI-2가 고른 쪽이 작게 표시. 키워드 ¹=AI-1, ²=AI-2, "키워드 없음"도 답 |
| ③ 한 줄 칸 | 직접 고치기 (글자 수·규칙은 바로 확인, 통과하면 답한 것) |
| 같게 본 칸도 고치기 | 장르·주제·나머지 축·키워드 후보(12자)·결정(대기 / 다른 갈래로) |
| **확인** | 질문을 다 고르면 켜진다. 무엇이든 고치면 확인이 풀리니 **마지막에 다시 확인** |
| **검수 결과 내려받기** | 확인한 카드만 파일(`<묶음>-review.json`)로 저장. 진행 상황은 이 브라우저에 저장됨 |

### 7-2. 결정 네 가지 — 언제 무엇을

| 결정 (페이지 문구) | 코드 | 언제 | 결과 |
|---|---|---|---|
| **넣기** | picked | 칸에 맞고, 태그·한 줄이 (고친 뒤) 믿을 만하다 | 앱 책 목록(books.json)에 들어간다 |
| **빼기** | dropped | 칸에 안 맞고 **어느 칸에도 안 맞는다** (안 다루는 것, 1절) | 앱에 들어가지 않고 **다시 오지 않는다**. 두 AI 모두 "맞음 아니요"면 처음부터 자동으로 빼기 |
| **대기** (= 예비) | reserve | 지금은 판단이 안 서거나 더 확인할 게 있다. 규칙에 걸린 채 두는 책 | 앱에 안 들어가고 파일에 남는다 (나중에 다시) |
| **다른 갈래로 (다시 태그)** | requeue | 🎯↔🍃 갈래가 틀렸다 (2-3절). 🎯→🍃면 장르 필수 | 이 책은 앱에 안 들어가고, **다음 묶음이 맨 먼저 새 갈래로 다시 태그**한다. 책을 잃지 않는다 |

고르는 순서: 이 칸에 맞나? → 아니다 → **다른 칸에는 맞나?** → 맞다 = 다시 태그 / 아니다 = 빼기. 맞다 → 고칠 게 있나? → 고쳤다 = 넣기 / 판단이 안 선다 = 대기.
기본값은 넣기 — 한 줄에 걸린 책도 한 줄을 고치고 확인하면 들어간다.
