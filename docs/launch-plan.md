## 1. 책 1,000권 (지금 376권 → +624)

- **방식은 지금 그대로 (사용자 결정)**: AI 둘이 따로 태그를 붙인다. 답이 다르거나 규칙에 걸린 책과 표본은 사람이 검수한다.
  "검수된 책으로만 추천"이 갈피의 강점이다. 자동 병합은 방식이 안정된 뒤에 따로 정한다.
- 하루 최대 100권(`MAX_DAILY`). 수동 실행을 여러 번 해서 이틀에 나눠 돌린다. 두 태그가 맞는 책만 남으므로 후보는 900~1,000권쯤 필요하다.
- 장르와 질문 길에 **고르게** 채운다. 모자란 길 끝 7곳(역사·사회·시사·호러·괴담·일기·편지·업무 글·갈등 대처)과 5권뿐인 장르를 먼저 채운다 (= v2 계획 3).
- 비용: 책 1권에 약 $0.012, 624권이면 약 $8. Anthropic 월 한도 $15 안에 들어간다 (사이트는 이제 Anthropic을 쓰지 않는다).
- [ ] 후보 공급량 확인 (도서관 정보나루·예스24에서 900권 이상 나오는지)
- [ ] 1차 대량 실행 → 검수 페이지에 걸리는 책 수 보고 일정 조정
- [ ] 1,000권 도달 → "갈피의 서재" 표시 확인

## 2. 질문 길 점검 — 취향을 정말 맞게 찾는가

- 질문 80개 × 선택지마다 표를 만든다. 이 답이 어떤 태그를 뜻하는지, 그 태그가 붙은 책이 몇 권인지, 실제로 나오는 책 예시 3권을 적는다.
- 특히 기분 질문 ("깊게 한 권" → 정말 두껍고 깊은 책이 나오는가). 지금은 책 두께 같은 실제 정보가 아니라, AI가 기준표대로 붙인 태그로 점수를 매긴다. 질문의 말과 태그 기준의 뜻이 맞는지 본다.
- 어긋난 곳은 사용자가 고르고, 고칠 방법(질문 문구 / 태그 기준 / 점수 규칙)을 정해 고친다. `simulate_draws.py`와 분포가 같아야 한다.
- [ ] 점검표 (Claude) → [ ] 사용자 확인 → [ ] 수정·테스트

## 3. 도감 v1 — 책갈피 모으는 맛 (PRD F-21 확장)

- **희귀 등급**: 일반 (지금 7종: 고양이·곰·토끼·여우·오리·고래·부엉이) → 희귀 (진짜 희귀한 동물: 레서판다·사막여우 …) → 전설 (용·백호 …). 등급이 높을수록 드물다.
  배경·소품에도 희귀한 것을 둔다 (예: 오로라 하늘, 벚꽃 언덕).
- **그림**: Claude가 지금 그림체(100×100, 투명, 창에서 55%)에 맞춰 SVG로 그린다. 사용자는 시안을 보고 고른다.
- **확률은 공개한다** (예: 일반 90% · 희귀 9% · 전설 1% — 숫자는 시안 때 정함). 돈으로 뽑는 기능은 없다 (F-21).
- **그림은 책과 무관하게 뽑는다** (원칙 2: 추천은 태그와 점수로만. 희귀 동물이 특정 책에 붙지 않는다).
- **도감에 들어가는 기준: 나온 책갈피 (사용자 결정 10-05)** — 책장에서 그 책갈피를 만난 순간 도감에 기록된다. 꽂지 않아도 된다.
  꽂은 것만 세면 "희귀 동물을 모으려고 책이 별로여도 꽂는" 사람이 생겨 꽂기가 책 만족도를 뜻하지 않게 된다. 그래서 꽂기와 도감을 떼어 놓는다.
- **기록은 로그인한 사람만** (도감이 계정에 남아야 하므로). 로그인하지 않은 사람에게는 어딘가에 "로그인하면 만난 책갈피가 도감에 모여요"를 알린다 (위치와 문구는 도감 시안 때 정함).
  만난 그림은 서버가 뽑기 seed로 다시 계산해 기록한다 (브라우저가 보낸 그림을 그대로 믿지 않는다 — 전설을 꾸며 넣지 못하게).
- 도감 화면: 등급별 칸. 못 만난 칸은 실루엣과 "?"로 보인다. 처음 만나면 "새 친구!", 모은 수 n / N.
- **분석**: 도감이 꽂기와 떨어져 있으므로, 꽂기는 계속 "책이 마음에 들었다"는 신호로 쓴다. `art.rare`가 이벤트에 남으므로 희귀가 꽂기에 영향을 주는지도 따로 본다.
- [x] 희귀 동물·배경 시안 (Claude) → [x] 사용자 선택 → [x] 도감 화면 시안 → [x] 구현 (taxonomy v1.3·PRD F-21·DESIGN A-04·C-25, `feat/collection-dex`, 10-05) → [ ] 사용자: Supabase 0004 적용 + Vercel `COLLECTION_SIGNING_SECRET` → 병합·배포
