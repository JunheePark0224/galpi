# 동물 캐릭터 넣는 곳

`DESIGN.md` A-01. 책갈피 아치 창 안에 들어가는 동물 얼굴.

## 무엇을
1차 **7종**: 고양이 · 곰 · 토끼 · 여우 · 오리 · 고래 · 부엉이 (다른 동물로 바꿔도 됨)
여유 있으면 3종 더 (예: 강아지 · 펭귄 · 다람쥐) → 최대 10종

## 규칙
- [ ] 캔버스 **100 × 100** 정사각형, 배경 **투명** (배경·소품은 코드가 따로 그림)
- [ ] 얼굴(머리)은 **가운데 아래쪽** — 얼굴 중심이 대략 (50, 60), 크기는 캔버스의 절반 안팎
- [ ] **선 없이 면으로**, 한 동물에 **색 4개 이내**
- [ ] 눈은 **까만 점 두 개** (`#2B2724`), 볼터치는 있어도 되고 없어도 됨
- [ ] 7종 모두 **같은 굵기·같은 단순함** — 한 가족처럼
- [ ] 글자·테두리·그림자 넣지 않기
- [ ] 다른 사람 캐릭터를 따라 그리지 않기 (참고만)

## 파일
- 형식: **SVG** (가장 좋음) 또는 **PNG 1000 × 1000, 투명 배경**
- 이름: `cat.svg`, `bear.svg`, `rabbit.svg`, `fox.svg`, `duck.svg`, `whale.svg`, `owl.svg` (영어 소문자)
- 이 폴더(`Galpi/assets/animals/`)에 넣고 채팅에 "넣었어"

## 순서
1. **1종만 먼저** 그려서 넣기 → Claude가 책갈피에 끼워 미리보기 보여줌 → 크기·위치·굵기 맞추기
2. 확정되면 나머지 6종
